Key Deliverables per Phase

Phase Deliverables
Phase 0
Foundation
  • Expo + TypeScript project scaffold with CI/CD (EAS Build)
  • Design system: high-contrast themes, large touch targets, semantic markup
  • Backend API proxy (Node.js) & TfL API registration
Phase 1
Voice Engine
  • On-device speech recognition (STT) & text-to-speech (TTS)
  • Intent parsing: natural language → structured commands
  • Multi-turn conversation flow & voice command system
  • Haptic feedback & audio cues
Phase 2
Navigation
  • TfL Journey Planner integration with voice-guided step-by-step directions
  • Transport mode selection via voice (bus, tube, walking)
  • Favourite destinations ("take me home") & journey history
  • High-contrast journey display for partially sighted users
Phase 3
NHS Portal
  • NHS App website embedded via WebView with voice overlay
  • Page content extraction & summarisation (read aloud)
  • Voice commands: "read messages", "request prescription"
  • NHS Login flow & session management
Phase 4
Polish
  • First-launch voice tutorial & onboarding
  • Settings: speech rate, voice type, contrast, text size
  • Error handling, offline mode, performance & battery optimisation
Phase 5
Launch
  • Automated end-to-end tests
  • User testing with visually impaired users
  • App Store & Google Play submission
  • Documentation & analytics setup

Assumptions & Notes

  • Day rate: £500/day + VAT
  • Working schedule: 2 days per week
  • Start date: April 2026 · Target MVP launch: October 2026
  • Platform: React Native + Expo (iOS & Android from single codebase)
  • NHS integration via WebView MVP — no API onboarding dependency
  • Navigation: TfL Journey Planner API (free, London-only for MVP)
  • Running costs scale with user count; estimates based on ~1,000 monthly active users
  • Post-launch NHS API work is contingent on NHS England onboarding approval
