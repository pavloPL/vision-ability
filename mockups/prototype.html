How it works — Architecture (Option 1: WebView)

📱 React Native App

  • expo-speech-recognition (on-device STT)
  • expo-speech (on-device TTS)
  • expo-location (GPS)
  • React Native WebView
  • VoiceContext provider
  • Accessibility layer
→

⚡ Your Backend (Node.js)

  • Proxies OpenAI calls (key security)
  • Proxies TfL API calls
  • Caches common journeys
  • Rate limiting
→

🧠 External APIs

  • OpenAI GPT-4o-mini (NLU)
  • TfL Journey Planner (routes)

🌐 NHS (via WebView — no API needed)

  • User opens nhsapp.service.nhs.uk in WebView
  • Logs in with NHS Login (OAuth in WebView)
  • App injects JS to extract page text
  • GPT-4o-mini summarises content
  • expo-speech reads it aloud
  • Voice commands navigate between pages
  • No NHS API onboarding required!
